1st most important Component:- JavaScript Events
JavaScript Events are actions performed by users or browsers on a webpage, 
such as clicking a button, typing text, moving a mouse or submitting a form. 
Events make webpages interactive and responsive.
JavaScript handles these events using event handlers like addEventListener(),
which executes a function when a particular event occurs.
caption is JavaScript Events makes webpages interactive through user actions.

2nd most important component :-CRUD OPERATIONS
CRUD stands for Create,Read,Update and Delete.These are the four basic operations used to manage data in a frontend application.
1. Create:Adding new data or records to the application.
2. Read:Displaying or retrieving existing data from the application.
3. Update:Modifying or editing existing data.
4. Delete:Removing unwanted data from the application.
Caption is CRUD OPERATIONS means create ,read ,update ,delete

3rd most important component:-REACT ROUTER
React Router is a JavaScript library used in React applications to enable navigation 
between different pages or components without reloading the entire webpage.
It helps create Single Page Applications by displaying different components
based on the URL.
Caption is React Router navigate between pages without reloading.

4th most important component:-Web Application
A web application is a software program that runs through a web browser and allows users to perform specific tasks online. 
For example online shopping ,Banking services and railway reservation systems. 
Web applications use technologies like HTML,CSS,JavaScript,React,databases, servers, and API.
Caption is Web Application is browser-based software that performs tasks online.

5th most important component:-User Interface & User Experience
User Interface (UI) is the visual part of a website that users interact with. 
A good UI makes an application attractive, responsive, helping users complete tasks quickly.

User Experience(UX) describes interact with a website is and how easy it is to use. 
It focuses on fast responses,clear information,simple navigation and user satisfaction. 
It ensures  that users can complete their goals comfortably.
Caption is User Interface (UI) & User Experience (UX) is UI focuses on appearance; UX focuses on usability.
