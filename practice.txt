JavaScript Events
JavaScript Events are actions performed by users or browsers on a webpage, 
such as clicking a button, typing text, moving a mouse or submitting a form. 
Events make webpages interactive and responsive.
JavaScript handles these events using event handlers like addEventListener(),
which executes a function when a particular event occurs.

CRUD OPERATIONS
CRUD stands for Create,Read,Update and Delete.These are the four basic operations used to manage data in a frontend application.
1. Create:Adding new data or records to the application.
2. Read:Displaying or retrieving existing data from the application.
3. Update:Modifying or editing existing data.
4. Delete:Removing unwanted data from the application.

REACT ROUTER
React Router is a JavaScript library used in React applications to enable navigation 
between different pages or components without reloading the entire webpage.
It helps create Single Page Applications (SPA) by displaying different components
based on the URL.

CRUD OPERATIONS:create,read,update,delete
REACT ROUTER: Navigate between pages without reloading.
